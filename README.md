# .github — réglages par défaut de l'organisation

Ce dépôt donne à **tous les dépôts de l'organisation** qui n'ont pas les leurs :

- le modèle de pull request (`.github/pull_request_template.md`) ;
- les formulaires d'issues (`.github/ISSUE_TEMPLATE/`) ;
- la politique de sécurité (`SECURITY.md`) ;
- le guide de contribution (`CONTRIBUTING.md`).

Un dépôt qui a son propre fichier du même nom l'emporte : pour les formulaires
d'issues, un dossier `.github/ISSUE_TEMPLATE/` dans le dépôt remplace TOUS ceux
d'ici.

**Ce dépôt est public**, comme GitHub l'exige pour appliquer ces réglages à
toute l'organisation : il ne contient rien d'interne. Les dépôts modèles
(`paddock-template-*`) restent privés.
